## ⚠️ Important: Known Issue

There's a known bug where admin and client sessions can overlap in the same browser. **Don't open both `/admin` and `/portal` at the same time in the same browser.**

Workarounds:
- Use different browsers
- Use private/incognito windows
- Test one account at a time

## 📝 How to Report Issues

When you find something that doesn't work:

1. **Note the exact steps** to reproduce it
2. **Describe what you expected** to happen
3. **Describe what actually happened**
4. **Try to repeat it** to confirm
5. **Fill it in** the Testing Report Template

**Example:**
```
What: Drug search not working
When: I was on /portal/db1
Steps: 
  1. Typed "Insulin" in search box
  2. Pressed Enter
Results: Nothing filtered, still showing all drugs
Severity: High
```

## 🔍 What NOT to Test

- Don't try to hack or break the website intentionally
- Don't test backend systems directly
- Don't worry about speed/performance (not part of this phase)
- Don't access features you're not authorized to
- Don't test on very old browsers

---

## 💡 Pro Tips

**Before Testing:**
- Use a modern browser (Chrome, Firefox, Safari, Edge)
- Close unnecessary tabs/programs
- Use good internet connection
- Have 2-3 hours available

**While Testing:**
- Take notes as you go
- Take screenshots of bugs
- Test on mobile - this is important!
- Be thorough and patient
- Don't rush

**After Testing:**
- Review your notes
- Verify your documentation is clear
- Double-check report is complete
- Send to team
